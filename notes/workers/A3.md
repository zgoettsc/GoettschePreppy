# A3 notes: generator and binder

Owner of `app/lib/**`, `app/binder/**`, `scripts/build-kit.mjs`, `scripts/test-generate.mjs`,
`tests/**`, `content/ai-blocks/README.md`.

## 1. File formats A3 consumes (for D1 regions, D2 plates/figures, content workers)

Everything below is optional at build time. When a file or field is missing, `build-kit` and the
generator degrade: missing values print the fill-in blank, missing plates print a captioned empty
frame, missing regions give the settings page a free-text county box. **No file below may contain a
URL in any field A3 copies into the binder** (A3 drops the fields named `url`, `home`, `api`,
`imageBase`; any other string containing `http` fails the build-kit check).

### 1.1 `data/regions/states/<XX>.json` (D1) — one file per state + DC, `XX` = two-letter code

```json
{
  "state": "SD",
  "state_name": "South Dakota",
  "state_em": "South Dakota Office of Emergency Management",
  "sources": ["noaa-ncei-normals-1991-2020", "usda-phzm-2023"],
  "defaults": { "...any county field below, used when a county lacks it..." },
  "counties": {
    "Lincoln County": {
      "fips": "46083",
      "zone": "5a",
      "last_frost": "May 5",
      "first_frost": "Sep 30",
      "growing_days": 148,
      "jan_low_f": 5,
      "jul_high_f": 85,
      "record_low_f": -40,
      "record_high_f": 110,
      "precip_in": 26.5,
      "snow_in": 40,
      "elevation_ft": 1500,
      "ecoregion": "Northern Glaciated Plains",
      "nws_office": "Sioux Falls, SD",
      "nwr": [ { "call": "WXL...", "freq": "162.475", "same": "046083" } ],
      "hazards": { "tornado": 3, "blizzard": 3, "ice_storm": 2, "flood": 2, "wildfire": 1,
                   "earthquake": 1, "hurricane": 1, "extreme_heat": 2, "extreme_cold": 3,
                   "drought": 2, "volcano": 1, "tsunami": 1, "landslide": 1 },
      "sun_hours_dec": 2.6,
      "sun_hours_jun": 6.3,
      "coastal": false
    }
  }
}
```

- County keys: the Census full name ("Lincoln County", "Orleans Parish", "Juneau City and
  Borough", "Richmond city"). Matching is case-insensitive and ignores a trailing
  County/Parish/Borough/Census Area/Municipality/city, so a profile county "lincoln" finds it.
- Every county field is optional. Missing numeric fields render as the fill-in blank.
- `coastal`: true when the county touches an ocean or Gulf coast (drives `is.coastal`).
- Hazard keys are exactly the 13 above (snake_case); rating 1 = low, 2 = moderate, 3 = high.
  Ratings drive `is.tornado_region` etc. (rating >= 2).
- `last_frost` / `first_frost`: free text date as it should print ("May 5").
- `nwr[].same`: six-digit SAME code as a string. `freq` as a string in MHz.
- `state_name` (and `state`) must be present; it is all the settings county picker needs besides
  the county keys.
- **For topo maps (G16) and route counties**, each county should also carry
  `"centroid": [lat, lon]` (decimal degrees) and `"bbox": [west, south, east, north]` (decimal
  degrees, lon/lat). Route counties = counties whose bbox contains a point on the straight line
  between the home and destination centroids. Optional `"topo_maps": [{ "title", "url", "date" }]`
  (USGS download addresses) overrides the automatic map search; these URLs go only into
  `kit.maps` for the relay's fetch-map, never into a binder.

Also accepted (fallback, same object shape): `data/regions/<XX>.json` directly in `data/regions/`.

### 1.2 `data/regions/ecoregions.json` (D1)

```json
{
  "Northern Glaciated Plains": {
    "plants": { "deadly": ["poison-hemlock", "water-hemlock"], "edible": ["dandelion", "cattail"] },
    "trees":  { "firewood": ["bur-oak", "green-ash"] },
    "states": ["SD", "ND", "MN"]
  }
}
```

Keys are EPA Level III ecoregion names exactly as used in the county `ecoregion` field. Plant and
tree values are keys in `images/index.json`. A county may also carry its own `plants` / `trees`
object (same shape) which overrides the ecoregion lists.

### 1.3 `images/index.json` (D2) — plant and tree plates

Same shape as the household binder's `images/index.json`:

```json
{
  "collections": { "usda-plants": { "org": "USDA NRCS PLANTS Database", "license": "..." } },
  "plants": [
    {
      "key": "poison-hemlock",
      "common": "Poison hemlock",
      "scientific": "Conium maculatum",
      "class": "deadly",            // deadly | lookalike | edible | firewood | medicinal | other
      "note": "One paragraph: why it matters, where you meet it.",
      "lookalikes": ["wild-carrot"],  // optional, plant keys
      "plates": [
        { "file": "images/plants/poison-hemlock/coma2_013_lhp.jpg",
          "shows": "What is in the frame and the feature to look at.",
          "collection": "usda-plants", "credit": "Photographer", "provider": "USDA NRCS",
          "license": "Public domain (US Government work)", "width": 900, "height": 600 }
      ]
    }
  ]
}
```

- `file` is relative to the repo root. JPEG or PNG or WebP. `url` may be present for provenance; A3
  never copies it.
- build-kit recompresses every plate to max 720 px on the long side, JPEG quality 62 (ImageMagick
  `convert` when installed; otherwise copied as-is) into `app/build/plates/<key>/<name>.jpg`.
  Ship originals at any size; aim for about 3 plates per species.
- Each plate image is stored once in a binder (a CSS class with the data URI), however many pages
  show it.

### 1.4 `figures/index.json` (figures worker) — line diagrams and PD figures

```json
{
  "fig-warm-room-layout": {
    "file": "figures/fig-warm-room-layout.svg",
    "caption": "The warm room: heater spot, two vents, barrier, CO alarm at pillow height.",
    "alt": "Plan view of one room ...",
    "credit": "GoettschePreppy (diagram, not to scale)",
    "source": null
  }
}
```

An array of objects with an `id` field is accepted too. SVG is inlined (scripts, event handlers,
`xmlns` attributes and any `href` to outside the file are stripped); JPEG/PNG become data URIs.
Unknown ids render as a captioned placeholder and are listed on the Review notes page.

### 1.5 `content/sections/32-region-appendix/` (region page builder)

If the region builder writes state pages, A3 expects one page per state with id
`32-NN-<state-slug>` (e.g. `32-42-south-dakota`) and the tag `state-xx` (lowercase code, e.g.
`state-sd`) in `tags`. The binder's Section 32 picker filters by that tag (or, failing that, by
the slug). If no Section 32 pages exist, build-kit generates one plain state page per state file
in `data/regions/` (`layer: generated`, id `32-NN-<slug>`, NN = alphabetical order by state name
with DC included) plus plate pages by ecoregion.

### 1.6 `content/ai-blocks/<block-id>.md` — see `content/ai-blocks/README.md`.

### 1.7 Kit-shipped source files for Large: `sources/archive/<key>.<ext>` (optional)

PD/open documents the kit ships go in `sources/archive/` named by source key (`.pdf`, `.html`,
`.txt`). build-kit copies them to `app/build/sources/` and lists them in `kit.json`.

## 2. Files A3 produces (for A2 and the owner)

- `app/build/kit.json` — no URLs anywhere except `maps` (USGS map addresses, only from D1's
  optional `topo_maps`). `{ version, built, pages:[{id, section, title, layer, danger_level, ...
  frontmatter, body}], sections:{NN: {folder, title}}, cards:[{id, page_id, title, options,
  settings_summary}], sources:{key:{title, org, date, licence_class, shipped}}, regions:{XX: state
  object}, ecoregions:{...}, plates:{key:{common, scientific, class, note, plates:[{src, shows,
  credit, license}]}}, figures:{id:{src|svg, caption, alt, credit}}, ai_blocks:{id: spec text},
  sizes:{small_bytes, large_bytes} }`. No URLs.
- `app/build/regions-lite.json` — `{ "SD": { "name": "South Dakota", "counties": ["Aurora County",
  ...] }, ... }`, every state + DC present (empty county list when D1 data is missing).
- `app/build/plates/**`, `app/build/figures/**`, `app/build/sources/**` assets fetched by
  `generate.js` at generation time (same origin as the settings page).
