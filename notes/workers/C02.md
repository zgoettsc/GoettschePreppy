## How the templating works on these pages

- 22-03 go-bags: `#each members` builds one bag table per person (conditions, allergies, meds from
  the member's own fields); age-band add-ons use `adults`, `teens`, `children`, `infants`, `elders`
  (each with `{{else}}` "no one in this age band right now", text always printed). Pets via `#each pets`.
- 22-06 medical kit: people table (`members`), verbatim meds table (`meds`, incl. where_kept, expiry,
  days_on_hand), `allergies`, `refrigerated_meds`; a 27-row module table (CL-01..CL-26 + 02-27) with
  "(in this household)" from `has.condition.CL-NN`. Rescue and cold-chain rules always printed.
- 22-05 vehicle kit: `#each vehicles`, seasonal add-ons marked by `is.cold_winters` / `is.hot_summers`,
  hazard notes by `is.*_region`, spare-tyre note by `has.hybrid` / `has.ev`.
- 22-04 / 26-0x: inventory and checklists pre-fill `gear.*` values and list `stations`, `panels`,
  `heaters`, `vehicles`, `meds`; priorities follow flags (rows marked "(this household)").
- 25-01: `region.home.last_frost/first_frost/growing_days/zone` + destinations via `d.region.*`;
  method is "weeks before/after frost dates" with a short/middle/long/no-frost season table, so it
  works for any zone.
- 25-03: utilities from `contacts.utility.*`; NWS office, state EM from `region.home.*`; NWR rows from
  `#each region.home.nwr`; destinations' NWS/EM from `d.region.*`. National numbers printed: 911,
  Poison Help, 988, Disaster Distress Helpline, National DV Hotline (all have source keys); 511 as
  "in many states". No local number is printed or guessed.
- 25-04: `size.large` switches the "what maps this binder carries" block (Large: USGS topo for home
  county, destination counties and route counties; Small: paper-map list + state outline); both
  are always described.
- 25-08: cards are Markdown tables (not ASCII boxes) because slot values are HTML-escaped and would
  show as `&#39;` inside code fences. Floors are copied word for word from 30-01.
