# Glossary: every term in plain words

**What this page is for.** If a word in this binder is unfamiliar, it should be here, in plain
words, with the page that explains it properly. **Nothing on this page is a procedure.** The
definitions orient you; the page in the last column does the work. The explainers in Section 29
(→ 29-01 to → 29-15) teach most of these words in context, one subject per page.

## Do this now

1. **Read "How this binder works" first.** Those terms explain how the whole book is organised.
2. **Make sure every adult knows the medical words in bold.** Under stress, a shared vocabulary
   is the difference between "they're acting funny" and "this is anaphylaxis, get the
   epinephrine."

## Medical

| Term | Meaning | Page |
|---|---|---|
| **Anaphylaxis** | A severe, fast, life-threatening allergic reaction affecting breathing or circulation. **Epinephrine is the treatment; antihistamines are not** | → 02-03 |
| **Epinephrine** | The medicine that treats anaphylaxis (adrenaline). Comes in **auto-injectors** (a pen pressed into the outer thigh) and a nasal spray. **A second dose may be needed** | → 02-03 |
| **Antihistamine** | An allergy medicine for itching and hives. **Never instead of epinephrine, never first** in anaphylaxis | → 02-03 |
| **Cross-contact** | An allergen carried onto safe food by a shared surface, utensil or hands | → 02-04 |
| **Type 1 diabetes** | The pancreas makes almost no insulin. **Insulin is not optional and has no substitute** | → 02-01 |
| **Type 2 diabetes** | The body does not use insulin well; treated with diet, tablets, injectables or insulin | → 02-05 |
| **Insulin** | The hormone that lets the body use sugar; a refrigerated protein medicine. **Frozen insulin is discarded** | → 02-01, → 29-07 |
| **Basal / bolus** | Background insulin / mealtime or correction insulin | → 02-01 |
| **Hypoglycaemia ("a low")** | Blood sugar too low: shaky, sweaty, confused. Can kill in minutes | → 02-01 |
| **Hyperglycaemia ("a high")** | Blood sugar too high | → 02-01 |
| **DKA (diabetic ketoacidosis)** | A life-threatening emergency when the body lacks insulin and burns fat, making **ketones** that acidify the blood. **Ketone strips catch it early** (CDC, Diabetic Ketoacidosis) | → 02-01 |
| **Ketones** | Acids made when the body burns fat for fuel; measured with urine or blood strips | → 02-01 |
| **CGM (continuous glucose monitor)** | A sensor worn on the skin that reads sugar levels all day | → 02-02 |
| **Insulin pump** | A worn device that delivers insulin; needs supplies, batteries and a backup plan | → 02-02 |
| **Glucagon** | A rescue medicine for a severe low when the person cannot swallow | → 02-01 |
| **Asthma / rescue inhaler** | Narrowing of the airways / the fast-acting inhaler that opens them | → 02-07 |
| **COPD** | Long-term lung disease; some people need **oxygen** from a concentrator (needs power) or cylinders | → 02-08 |
| **CPAP** | A powered machine that keeps the airway open during sleep | → 02-24 |
| **Anticoagulant (blood thinner)** | Medicine that slows clotting; bleeding is harder to stop | → 02-10 |
| **Seizure** | A burst of abnormal brain activity, often with jerking or blank staring | → 02-11 |
| **Naloxone** | A medicine that reverses an opioid overdose | → 02-17 |
| **Prescriber** | The doctor, nurse practitioner or other clinician who prescribes a medicine | → 12-07 |
| **OTC (over the counter)** | Medicine sold without a prescription; its box carries a **Drug Facts** label | → 29-14 |
| **Drug Facts label** | The standard box label: active ingredient, uses, warnings, directions | → 29-14 |
| **Expiry date (EXP) / lot number (LOT)** | The last date the maker guarantees full strength / the batch it came from | → 29-14 |
| **Cold chain** | Keeping a medicine within its temperature range from start to finish | → 29-07 |
| **Excursion** | A time a medicine spent outside its labelled range. **Freezing is a cliff; heat is a slope** | → 29-07 |
| **Evaporative cooling pouch** | A wetted pouch that cools medicine as water evaporates; no power needed | → 12-21 |
| **Hypothermia** | Dangerous drop in core body temperature; **happens above freezing when wet and windy** | → 08-05 |
| **Frostbite** | Frozen skin and tissue, usually fingers, toes, ears, nose. **Minutes at extreme wind chill** | → 08-05 |
| **Heat exhaustion / heat stroke** | Overheating with heavy sweating and weakness / a life-threatening emergency with confusion and very high body temperature | → 17-04 |
| **ORS (oral rehydration solution)** | Water with the right salt and sugar to replace what diarrhoea and vomiting lose | → 12-05 |
| **Tourniquet** | A tight band above a bleeding arm or leg wound that stops the blood. The floor (→ 30-01): **Never loosen a tourniquet once placed while help can still come; mark the time. If no help will ever come, the conversion decision is DC-25 (→ 30-26).** | → 12-02 |
| **Wound packing** | Stuffing gauze firmly into a deep wound and pressing to stop bleeding | → 12-02 |
| **Triage** | Sorting injured people by who benefits most from limited help | → 12-16 |
| **Sepsis** | A life-threatening body-wide response to infection | → 12-04 |
| **Antibiotic** | A medicine that kills bacteria or stops them growing. **Does nothing for viruses** (colds, flu, most coughs and sore throats) | → 12-22, → 12-23 |
| **Antibiotic resistance** | Bacteria that survive a drug and multiply, so it stops working for that person and others | → 30-17 |
| **mg/kg** | Milligrams of medicine for each kilogram the person weighs. A published child dose in mg/kg is always checked against the **published maximum**; this binder never works one out | → 12-22 |
| **mg/5 mL** | How much medicine is in each 5 mL (one teaspoon) of a liquid. The same medicine comes in different strengths; **read the bottle** | → 12-22, → 29-14 |
| **C. diff** | *Clostridioides difficile*: a severe diarrhoea any antibiotic can cause, even weeks after the course | → 12-23 |
| **TCCC** | Tactical Combat Casualty Care: the US military's battlefield first-aid guidelines, written for trained medics | → 12-24 |
| **CPR** | Chest compressions (and breaths) to keep blood moving when the heart stops | → 12-18 |
| **Medical ID** | A bracelet, tag or card naming a condition or allergy for responders | → 25-09 |

## Water

| Term | Meaning | Page |
|---|---|---|
| **Potable** | Safe to drink | → 29-06 |
| **Clear is not clean** | Water can look perfect and still carry germs or chemicals | → 29-06 |
| **Germs: bacteria, viruses, parasites** | Bacteria are tiny living cells; viruses are far smaller and need a host; parasites (such as Giardia) include tough cysts that resist chlorine | → 29-06 |
| **Rolling boil** | Big bubbles that keep coming when stirred; **1 minute**, or **3 minutes** at high altitude, makes water safe from germs (EPA) | → 03-04 |
| **Filtration** | Straining out particles and many germs. **A filter does not remove salt**, and plain filters do not remove dissolved chemicals | → 03-04 |
| **Micron; absolute vs nominal** | A millionth of a metre. "Absolute" is the largest gap a filter lets through; "nominal" is an average and promises less | → 29-06 |
| **Disinfection** | Killing germs, by boiling, chemicals or ultraviolet light (UV) | → 03-04 |
| **Distillation** | Boiling water and collecting the steam. **Removes salt** and most chemicals | → 03-03 |
| **Turbidity** | Cloudiness. **Settle and pre-filter cloudy water before disinfecting** | → 29-06 |
| **Residual** | Chlorine left over after it has done its work: a faint smell means it is still protecting the water | → 29-06 |
| **ppm (parts per million)** | How strong a chemical is in water: 1 ppm is one part in a million | → 29-05 |
| **Sodium hypochlorite** | The active chemical in household bleach | → 29-05 |
| **Calcium hypochlorite ("pool shock", "cal-hypo")** | A dry chlorine powder or granule; made into a stock solution for water | → 29-05 |
| **Trichlor / dichlor** | Pool tablets with stabilisers: **not** for drinking water | → 29-05 |
| **Never-mix rule** | **Bleach or pool shock is never mixed with ammonia, acids or other cleaners.** Chlorine gas | → 30-01 |
| **Greywater / blackwater** | Used wash water / sewage | → 13-03, → 13-01 |
| **Bti** | A natural larvicide that kills mosquito larvae in standing water | → 03-08 |
| **SAME, NWR** | See Communications | |

## Food, canning and growing

| Term | Meaning | Page |
|---|---|---|
| **pH** | How acid something is. **Lower is more acid** | → 29-08 |
| **High-acid / low-acid food** | pH 4.6 or lower (most fruit, pickles) / above 4.6 (vegetables, beans, meat, soups) | → 29-08 |
| **Botulism** | A deadly illness from a toxin made by spores in sealed low-acid food. **No warning taste or smell** | → 29-08 |
| **Spores** | Dormant, heat-resistant forms of bacteria that survive boiling | → 29-08 |
| **Boiling-water canner** | A deep pot that holds jars under boiling water; for **high-acid** foods only | → 04-04 |
| **Pressure canner** | A heavy pot that holds jars under pressure to reach about 240 to 250 °F; **required for low-acid foods**. **A pressure cooker is not a pressure canner** | → 04-05 |
| **Dial gauge / weighted gauge; psi** | Two ways a canner shows pressure / pounds per square inch | → 29-08 |
| **Venting** | Letting steam escape from a canner for a set time before pressurising | → 29-08 |
| **Altitude adjustment** | Higher places need longer times or more pressure; the recipe's table governs | → 29-08 |
| **Headspace** | The gap between the food and the lid, set by the recipe | → 29-08 |
| **Hot pack / raw pack** | Filling jars with hot, cooked food / raw food | → 29-08 |
| **Tested recipe** | A process proven safe by a recognised authority (USDA, NCHFP, Extension). **Use only tested recipes** | → 04-05 |
| **The seal** | The lid pulled down by vacuum as a jar cools; an unsealed jar is refrigerated or reprocessed | → 29-08 |
| **Curing / fermentation** | Preserving with salt (and sometimes nitrite) / with helpful microbes that make acid | → 04-07, → 04-08 |
| **Oxygen absorber / mylar** | A sachet that removes oxygen / a metallised bag that keeps it out; together they make dry food keep for years | → 04-03 |
| **"Best if used by", "Sell by", "Use by"** | Quality and display dates, not safety dates. Infant formula is the exception: its date is required by federal law, and it is followed | → 29-14 |
| **Open-pollinated (heirloom) / hybrid (F1)** | Seed that comes true when saved / seed from a cross that does not | → 05-03 |
| **Frost date** | The median date of the last spring or first fall frost; half of years are worse | → 25-01 |
| **Hardiness zone** | The USDA zone for a place's average coldest winter night; tells which perennials survive | → 25-01 |
| **Days to maturity** | On a seed packet: days from planting to harvest | → 25-01 |
| **Hardening off / succession sowing** | Getting seedlings used to outdoors over one to two weeks / small sowings every few weeks | → 25-01 |

## Fire, fuel and heat

| Term | Meaning | Page |
|---|---|---|
| **Gasoline** | Thin, very volatile engine fuel. **Never in a heater or lamp, never indoors** | → 29-01 |
| **Diesel** | Heavier oily fuel for diesel engines and ducted heaters vented outdoors | → 29-01 |
| **Kerosene (1-K, K-1)** | A lighter oily fuel; **1-K** is the clear grade for indoor wick heaters | → 29-01 |
| **Propane / butane** | Gases stored as liquid under pressure in cylinders; butane fails in freezing cold | → 29-01 |
| **White gas (camp fuel)** | A very volatile liquid for camp stoves; as dangerous to store as gasoline | → 29-01 |
| **Lamp oil** | Refined liquid paraffin for oil lamps; a swallowed mouthful can enter the lungs (call Poison Help) | → 29-01 |
| **Ethanol blend** | Pump gasoline with alcohol in it (often about 10 %); it pulls in water and ages | → 29-01 |
| **Stabiliser** | An additive that slows fuel ageing; it cannot fix stale fuel | → 06-06 |
| **Jar test** | Pouring a sample of fuel into a clear jar to check for water or cloudiness | → 29-01 |
| **Carbon monoxide (CO)** | A gas from anything that burns: **no colour, no smell, no taste, and lethal** (CDC, Carbon Monoxide Poisoning: Basics) | → 29-03 |
| **CO alarm (and ppm display)** | A battery device that sounds when CO builds up; a model with a number shows low levels the alarm waits on | → 29-03 |
| **Vented / unvented** | Exhaust goes outdoors through a pipe / exhaust stays in the room | → 08-04 |
| **Pilot light** | A small flame that is always lit on some gas appliances; it can ignite leaking gas or vapour | → 29-01 |
| **Seasoned wood** | Split and dried **6 to 12 months** to under about 20 % moisture | → 06-03 |
| **Cord / face cord** | 4 × 4 × 8 ft of stacked wood (128 cubic ft) / about a third of that | → 25-02 |
| **BTU, BTU/h** | A unit of heat / heat per hour, how heaters are rated | → 25-02 |
| **Creosote** | Tar that builds up in chimneys from smoky fires; it causes chimney fires | → 06-09 |
| **Rocket stove** | A small, efficient wood stove that burns sticks hot and clean | → 07-02 |
| **Banking a fire** | Covering coals so the fire survives overnight | → 06-02 |
| **Tare weight (TW)** | The empty weight stamped on a propane cylinder's collar | → 29-14 |
| **DOT specification** | The federal standard stamped on a pressure cylinder | → 29-14 |
| **Flame mitigation device** | A mesh in a newer fuel can's spout that helps stop flame entering the can | → 29-14 |
| **ABC extinguisher; PASS** | A fire extinguisher for ordinary, liquid and electrical fires / Pull, Aim, Squeeze, Sweep | → 29-12 |
| **Fire blanket** | A flame-resistant sheet to smother a small fire, such as a pan fire | → 29-12 |
| **Smoke alarm: ionisation / photoelectric** | Two sensor types: quicker to flaming fires / quicker to smouldering fires. **Smoke alarms do not detect CO** | → 29-12 |

## Power and electricity

| Term | Meaning | Page |
|---|---|---|
| **Volts, amps, watts** | Electrical "pressure", "flow", and the rate of use (**watts = volts × amps**) | → 29-02 |
| **Watt-hours (Wh), kilowatt-hours (kWh)** | Energy: watts × hours. **What batteries are sized in.** 1 kWh = 1,000 Wh | → 29-02 |
| **Amp-hours (Ah)** | Battery capacity at a voltage: **Wh = Ah × volts** | → 29-02 |
| **Power station** | A portable battery with outlets and an inverter inside | → 29-02 |
| **Inverter** | Turns battery (DC) power into household (AC) power; loses some energy doing it | → 29-02 |
| **AC / DC** | Alternating current from wall outlets / direct current from batteries and solar | → 09-12 |
| **LiFePO4 (LFP)** | Lithium iron phosphate, a long-lived, safer lithium battery; **must not be charged below freezing** unless its battery system blocks cold charging | → 29-02 |
| **Lead-acid** | Car, marine and AGM batteries: heavy, and damaged by deep draining | → 29-02 |
| **Depth of discharge** | How far a battery is drained; deeper shortens its life | → 09-07 |
| **Solar panel; charge controller** | Turns sunlight into DC power / regulates it into the battery | → 09-02 |
| **Voc, Isc** | A panel label's open-circuit volts and short-circuit amps; they limit what a station can accept | → 28-07 |
| **Peak sun hours** | Hours of full-strength sun a day; far fewer in December | → 09-05 |
| **Data plate** | The label on an appliance with its volts, watts or amps, and model | → 29-14 |
| **Phantom load** | Power drawn by things you forgot were on | → 09-01 |
| **Panel, breaker, main breaker** | The box where house wiring starts / a switch that trips on overload / the one switch that cuts the whole house | → 29-04 |
| **GFCI** | An outlet or breaker that cuts power fast if current leaks, as in a wet location | → 29-04 |
| **Transfer switch / interlock / inlet** | Ways to feed house circuits from a generator safely, with the grid locked out / the outdoor socket the generator cord plugs into | → 29-04 |
| **Backfeeding; "suicide cord"** | Pushing generator power into house wiring without a transfer switch or interlock, often with a double-plug cord. **Never.** It electrocutes line workers | → 30-01 |
| **Cord-and-plug conversion** | Giving a hard-wired appliance (furnace, well pump) a plug so it can run from a generator cord | → 30-08 |
| **Wire gauge (AWG)** | Wire thickness: **a lower number is a thicker wire** | → 29-04 |
